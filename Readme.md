# Lead Tracker

Lead Tracker is a lightweight Chrome extension built to help sales teams, marketers, and researchers keep track of important web pages and potential leads in one place.

## Overview

Instead of bookmarking links manually or losing valuable pages in a browser tab, users can quickly save URLs they want to revisit later. The extension allows them to:

- Add a URL manually
- Save the current active tab with one click
- View all stored leads in a simple list
- Remove saved links when they are no longer needed
- Keep leads saved locally in the browser for easy access

## Why it is useful

This project is especially useful for professionals who work with leads and online prospects. Sales teams can save company pages, contact-related links, product pages, or research sources without leaving their browser. It helps organize potential opportunities in a fast and efficient way.

## Features

- Simple popup interface
- Save current page URL instantly
- Add custom URLs manually
- Clear all saved leads with a single action
- Persistent storage using browser localStorage
- Minimal and easy-to-use design

## Tech Stack

- HTML
- CSS
- JavaScript
- Chrome extension APIs

## How to use

1. Open the extension in Chrome.
2. Paste a URL into the input box or use the "Save Tab" button to capture the current page.
3. Your saved leads will appear in the list.
4. Click any saved link to open it again.
5. Use the delete option to remove all saved leads when needed.

## Project Goal

The goal of Lead Tracker is to make lead management more efficient by turning browsing into a structured, searchable list of potential opportunities and useful web resources.
